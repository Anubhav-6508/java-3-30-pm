


  ----------------------------------
  QUESTION 1: EMPLOYEE INFORMATION
  ----------------------------------

Create a parent class Employee containing: - employeeId - employeeName -
salary

Create a child class Developer containing: - programmingLanguage -
experience

Requirements: 1. Inherit Employee into Developer. 2. Create constructors
in both classes. 3. Create a Developer object. 4. Display all employee
and developer information.

  QUESTION 3: VEHICLE MANAGEMENT

  ------------------------------------
  QUESTION 6: ONLINE COURSE DETAILS
  ------------------------------------

Create a parent class Course containing: - courseId - courseName -
durationInMonths

Create a child class ProgrammingCourse containing: -
programmingLanguage - projectCount - mentorName

Requirements: 1. Use single inheritance. 2. Create parameterized
constructors in both classes. 3. Initialize the parent-class properties
using super(). 4. Create at least three ProgrammingCourse objects with
different details. 5. Display all inherited and child-class properties.
6. Do not use method overriding or method overloading.

  INSTRUCTIONS

5.  First try to write the code independently, then test it.
